Keyboard Navigation Test Page

This page tests the enhanced keyboard navigation implementation for StackMap.

Key Improvements:

  • ✅ Reduced navigation debounce from 100ms to 50ms
  • ✅ Removed two-key shortcuts (g h, g t, g s)
  • ✅ Added shortcut conflict detection
  • ✅ Focus preservation during virtual scrolling
  • ✅ Undo system with Ctrl+Z
  • ✅ Emergency escape (3x ESC)
  • ✅ Visual shortcut hints
  • ✅ Focus mode (F key)
