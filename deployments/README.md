# Deployment Reports

This directory contains deployment reports generated by the three-tier deployment system.

## Report Format

Reports are automatically generated after each deployment with the filename format:
```
YYYYMMDD-HHMMSS-{tier}-report.txt
```

Example: `20251010-143045-beta-report.txt`

## Report Contents

Each report includes:
- **Tier**: qual, beta, or prod
- **Version**: Deployed version number
- **Time**: Deployment duration
- **Date**: Deployment timestamp
- **Branch**: Git branch
- **Commit**: Git commit hash
- **Platforms Deployed**: List of deployed platforms (web, iOS, Android)
- **Validation**: Pre-deployment validation results
- **Verification**: Post-deployment verification results
- **Next Steps**: Tier-specific recommendations

## Viewing Reports

### Latest Deployment
```bash
# View latest deployment (any tier)
ls -t deployments/*.txt | head -1 | xargs cat

# View latest for specific tier
ls -t deployments/*-beta-report.txt | head -1 | xargs cat
```

### Recent History
```bash
# List last 10 deployments
ls -t deployments/*-report.txt | head -10
```

### Error Reports

Error reports are also saved here with the format:
```
YYYYMMDD-HHMMSS-{tier}-error.txt
```

These contain error messages, recent git changes, and environment details.

## Report Generation

Reports are automatically generated by the deployment library (`scripts/lib/reporting.sh`).

To manually generate a report in a script:
```bash
source scripts/lib/reporting.sh
generate_deployment_report "prod" "2025.10.10.2"
```

## Cleanup

Reports are gitignored by default. To clean up old reports:
```bash
# Remove reports older than 30 days
find deployments -name "*.txt" -mtime +30 -delete
```
