CPANEL STEPS:
1. Login to cPanel
2. Open File Manager
3. Navigate to public_html/stackmap (or your subdomain)
4. Upload all production files
5. Set permissions (644 for files, 755 for folders)

□ Check browser console (should be clean)
□ Test creating a user
□ Test adding activities
□ Test offline mode (go offline, reload)
□ Test on mobile device
□ Clear Cloudflare cache (if using)
