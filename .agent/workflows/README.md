# Antigravity Workflows

This directory contains the migrated Atlas workflows for use with Antigravity.

## Available Workflows

### 1. Quick Workflow (`/quick`)

**Time**: 5-15 min
**Use for**: Typos, colors, config updates, single-line fixes.

- **Phase 1**: Make Change
- **Phase 2**: Deploy

### 2. Standard Workflow (`/standard`)

**Time**: 30-60 min
**Use for**: Most bugs, small features, refactoring (2-5 files).

- **Phase 1**: Research
- **Phase 2**: Plan
- **Phase 3**: Implement
- **Phase 4**: Review
- **Phase 5**: Deploy

### 3. Full Workflow (`/full`)

**Time**: 2-4 hours
**Use for**: Complex features, new modules, security changes.

- **Phase 1**: Research
- **Phase 2**: Story Creation
- **Phase 3**: Planning
- **Phase 4**: Adversarial Review
- **Phase 5**: Implementation
- **Phase 6**: Testing
- **Phase 7**: Validation
- **Phase 8**: Clean-up
- **Phase 9**: Deployment

## How to Use

Simply type the slash command in the chat:

- `/quick`
- `/standard`
- `/full`

Or ask Antigravity to "start the standard workflow".
