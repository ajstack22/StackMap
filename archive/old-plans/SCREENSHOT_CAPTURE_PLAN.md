## Screenshot Capture Process

### Preparation
1. Ensure all devices on v25.08.12.3
2. Import demo-data-kids.json
3. Verify Emma profile is active
4. Check theme colors are vibrant
5. Ensure good lighting conditions

### For Each Screenshot
1. Clean status bar (no notifications)
2. Full battery indicator
3. Strong WiFi signal
4. No system alerts visible
5. Proper time display (9:41 AM for iOS)

### Quality Checks
- [ ] No blurry text
- [ ] Proper contrast with themes
- [ ] All UI elements visible
- [ ] No cut-off content
- [ ] Consistent styling
- [ ] Age-appropriate content
