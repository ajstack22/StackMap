# Google Play Store Screenshot Specifications

## Requirements
- Format: PNG or JPEG
- Minimum: 2 screenshots
- Maximum: 8 screenshots per device type
- File size: Max 8MB per screenshot

## Phone Screenshots (Required)
- Dimensions: 1080 x 1920 pixels (9:16 aspect ratio)
- Alternative: 1242 x 2208 pixels

### Recommended Screenshots:
1. **Home Screen** - Show multiple user profiles with colorful cards
2. **Daily Routine View** - Display a child's morning routine with emoji cards
3. **Activity Completion** - Show the satisfying tap-to-complete interaction
4. **Card Creation** - Demonstrate creating a new activity with emoji picker
5. **Card Library** - Show pre-made activity templates
6. **Grown-up Mode** - Display the protected editing interface
7. **Themes** - Show different color theme options
8. **Success Screen** - Completed routine with celebration

## Tablet Screenshots (Optional but Recommended)
- 7-inch tablet: 1200 x 1920 pixels
- 10-inch tablet: 1600 x 2560 pixels

### Recommended Tablet Screenshots:
1. **Split View** - Show Today and Tomorrow side by side
2. **Family Dashboard** - Multiple user routines on larger screen
3. **Detailed Card View** - Larger cards with more visible details

## Screenshot Guidelines

### Visual Style:
- Clean backgrounds (use app's gradient style)
- Realistic device frames (optional)
- Clear, legible text
- Highlight key features with subtle annotations
- Use actual app UI (no mockups)

### Content Guidelines:
- Show diverse family representations
- Include variety of activities (morning, school, bedtime)
- Display completed and pending activities
- Use child-friendly emoji selections
- Avoid any personally identifiable information

### Text Overlay Suggestions:
- Use app's Comic Relief font
- Keep text minimal and action-oriented
- Examples:
  - "Tap to complete!"
  - "Visual schedules that work"
  - "Build independence daily"
  - "Your family, your routines"

### Color Palette:
- Primary: #667eea (Purple/Indigo)
- Success: #48bb78 (Green)
- Background gradients from app
- High contrast for accessibility

## File Naming Convention:
- phone-01-home-screen.png
- phone-02-daily-routine.png
- phone-03-tap-complete.png
- tablet-01-split-view.png
- tablet-02-family-dashboard.png

## Localization:
Create separate screenshot sets for each language, showing:
- Localized UI elements
- Culturally appropriate activities
- Local time formats
