Feature Graphic Specifications

  • Dimensions: 1024 × 500 pixels
  • Format: PNG (24-bit) or JPEG
  • File size: Max 1MB
  • Purpose: Displayed at the top of your Play Store listing
  • Requirements: No alpha transparency, must be flat image
  • Best practices: Include app name, avoid small text, use brand colors

📸 How to Export These Graphics

  1. Open this file in Chrome or Firefox
  2. Right-click on the feature graphic you want to use
  3. Select "Save image as..." or use browser screenshot tool
  4. For pixel-perfect export:
    • Open DevTools (F12)
    • Select the feature-graphic element
    • Right-click → "Capture node screenshot"
  5. Save as PNG for best quality
  6. Verify dimensions are exactly 1024×500 pixels
