# Google Play Store Feature Graphics Specifications

## Feature Graphic (Required)
- **Dimensions**: 1024 x 500 pixels
- **Format**: PNG or JPEG (PNG preferred)
- **File size**: Max 1MB
- **Usage**: Displayed at the top of your store listing

### Design Guidelines:
- Eye-catching hero image that represents your app
- Include app name and tagline
- Show key visual elements (emoji cards, routines)
- Maintain brand consistency
- Ensure text is readable at all sizes

### Recommended Design:

## Promotional Graphics

### TV Banner (Android TV)
- **Dimensions**: 1280 x 720 pixels
- **Format**: PNG or JPEG
- **Usage**: For Android TV devices

### Promo Video Thumbnail
- **Dimensions**: 1280 x 720 pixels (16:9)
- **Format**: PNG or JPEG
- **Usage**: If you add a promotional video

## Design Elements to Include:

### Visual Components:
1. **App Logo/Icon** - Prominently displayed
2. **Emoji Cards** - Show the visual nature
3. **Completion Checkmarks** - Show progress
4. **Device Mockups** - Phone/tablet showing app
5. **Brand Colors** - Purple gradient (#667eea)

### Text Elements:
- App name: "StackMap"
- Tagline: "Visual Routines Made Simple"
- Sub-tagline: "Routine Ready"
- Key benefit: "Build Independence Daily"

### Color Palette:
```
Primary: #667eea (Purple/Indigo)
Secondary: #5a67d8 (Darker Purple)
Success: #48bb78 (Green)
Background: Linear gradient (#667eea to #5a67d8)
Text: #FFFFFF (White) or #1a202c (Dark)
```

### Typography:
- Primary: Comic Relief (matches app)
- Fallback: Rounded, friendly sans-serif
- Ensure high contrast for readability

## File Naming:
- feature-graphic.png
- tv-banner.png
- promo-video-thumb.png

## Design Tips:
1. **Focus on Benefits**: Show what the app does, not just features
2. **Emotional Connection**: Include imagery that resonates with parents
3. **Clear Hierarchy**: Most important info should be immediately visible
4. **Consistent Branding**: Match the app's visual style
5. **Test at Size**: View at actual display size to ensure readability

## Do's and Don'ts:

### Do's:
- Use actual app UI elements
- Include diverse representations
- Show the app in action
- Maintain visual hierarchy
- Use brand colors consistently

### Don'ts:
- Don't use generic stock photos
- Don't overcrowd with text
- Don't use low contrast
- Don't misrepresent features
- Don't forget mobile optimization
