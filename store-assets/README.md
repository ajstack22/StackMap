# StackMap Store Assets

This directory contains all marketing materials and assets needed for publishing StackMap to Google Play Store and Apple App Store.

## Directory Structure

```
store-assets/
├── google-play/           # Google Play Store specific assets
│   ├── descriptions/      # Short and full descriptions
│   ├── screenshots/       # Screenshot specifications
│   └── graphics/          # Feature graphics specs
├── app-store/            # Apple App Store specific assets
│   ├── descriptions/     # App Store descriptions
│   ├── screenshots/      # iOS screenshot specifications
│   └── graphics/         # App icon and graphics specs
└── common/               # Shared assets for both platforms
    ├── brand-assets/     # Logos and brand guidelines
    ├── legal/           # Privacy policy and terms
    └── support/         # Support documentation
```

## Quick Reference

### App Descriptions
- **Google Play Short**: 80 character limit
- **Google Play Full**: 4000 character limit
- **App Store Subtitle**: 30 character limit
- **App Store Description**: 4000 character limit

### Screenshot Requirements
- **Google Play**: Min 2, Max 8 per device type
- **App Store**: Min 3, Max 10 per device size
- **Format**: PNG (preferred) or JPEG

### Key Files
- `/common/legal/privacy-policy.md` - Privacy policy for both stores
- `/common/support/support-documentation.md` - FAQ and help content
- `/common/aso-keywords.md` - Keywords for app store optimization
- `/common/promotional-text.md` - Marketing copy and templates

## Publishing Checklist

### Pre-Launch
- [ ] Create developer accounts for both stores
- [ ] Prepare app icons in all required sizes
- [ ] Take screenshots on actual devices
- [ ] Create feature graphics from specifications
- [ ] Review and finalize all descriptions
- [ ] Set up support email/website
- [ ] Test app on multiple devices

### Google Play Store
- [ ] Upload APK or App Bundle
- [ ] Add short description (80 chars)
- [ ] Add full description (4000 chars)
- [ ] Upload feature graphic (1024x500)
- [ ] Upload screenshots (min 2)
- [ ] Select categories
- [ ] Add content rating questionnaire
- [ ] Set up pricing (free)
- [ ] Add privacy policy URL

### Apple App Store
- [ ] Upload to App Store Connect
- [ ] Add app name and subtitle
- [ ] Add description
- [ ] Upload app icon (1024x1024)
- [ ] Upload screenshots for each device
- [ ] Add keywords (100 chars)
- [ ] Select categories
- [ ] Add age rating
- [ ] Add privacy policy URL
- [ ] Submit for review

## Asset Creation Guidelines

### Screenshots
1. Use actual app interface (no mockups)
2. Show key features in action
3. Include diverse user representations
4. Add minimal text overlays if needed
5. Ensure high contrast and readability

### Graphics
1. Maintain brand consistency
2. Use official color palette
3. Include app icon prominently
4. Keep text minimal and impactful
5. Test at actual display sizes

### Descriptions
1. Lead with main benefit
2. Use bullet points for features
3. Include social proof
4. End with call to action
5. Optimize for keywords naturally

## Localization

When translating assets:
1. Maintain tone and brand voice
2. Adapt cultural references appropriately
3. Verify technical terms
4. Test character limits
5. Use native speakers for review

## Updates and Maintenance

- Review keywords monthly
- Update screenshots quarterly
- Refresh descriptions based on user feedback
- Monitor competitor changes
- Track ASO performance metrics
