### StackMap Launches Free Visual Routine App for Special Needs Families

*Open-source progressive web app helps children with autism and ADHD build independence through picture schedules*

[CITY, Date] – StackMap, a new visual routine builder designed specifically for families with special needs children, launches today as a completely free, ad-free progressive web application. Built by a parent who understands the daily challenges of special needs parenting, StackMap transforms abstract daily schedules into concrete, visual steps that children can understand and follow independently.

"Every morning used to be a battle until we started using visual schedules," said [Creator Name], StackMap's developer. "I built StackMap to be the tool I wished existed - simple enough for kids to use independently, flexible enough for different family needs, and respectful of privacy."

**Key Features Include:**
- Picture-based schedules using emojis and colors
- Multiple user profiles for different family members
- One-tap completion for building independence
- Protected "Grown-up Mode" to prevent accidental changes
- Works offline with optional cloud backup
- Pre-made activity library for quick setup

Unlike other scheduling apps, StackMap prioritizes privacy with a local-first approach - all data stays on the user's device unless they choose to enable optional Google Drive sync.

The app has been tested extensively with families of children with autism, ADHD, and other developmental differences, incorporating feedback from occupational therapists and special educators.

StackMap is available immediately at [URL] and works on any device with a modern web browser. As a progressive web app, it can be installed like a native app while maintaining the flexibility of web technology.
