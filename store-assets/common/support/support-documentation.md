# StackMap Support Documentation

## Welcome to StackMap Support

We're here to help you make the most of StackMap for your family. Whether you're just getting started or need help with a specific feature, you'll find answers here.

## Quick Start Guide

### 1. First Time Setup
1. Open StackMap in your web browser
2. Tap "Add User" to create profiles for family members
3. Choose a name and color for each person
4. Start with one user to keep things simple

### 2. Creating Your First Routine
1. Select a user from the home screen
2. Tap the "+" button to add an activity
3. Choose an emoji and add a short description
4. Arrange activities in order by dragging
5. Tap "Save" when done

### 3. Using Routines Daily
1. Child opens their routine
2. Tap each card as they complete the activity
3. Cards turn green when completed
4. Celebrate when all activities are done!

## Frequently Asked Questions

### Getting Started

**Q: Do I need to create an account?**
A: No! StackMap works immediately without any sign-up. Just open and start using it.

**Q: Is StackMap free?**
A: Yes, StackMap is completely free to use with no hidden costs or in-app purchases.

**Q: What devices work with StackMap?**
A: StackMap works on any device with a modern web browser - phones, tablets, computers, and more.

### Creating Routines

**Q: How many activities can I add?**
A: You can add as many activities as needed. We recommend starting with 5-8 for younger children.

**Q: Can I use the same routine for different days?**
A: Yes! Create different routines for Today and Tomorrow, or copy routines between days.

**Q: How do I rearrange activities?**
A: In edit mode (Grown-up Mode), press and hold an activity card, then drag it to a new position.

### Managing Users

**Q: How many users can I create?**
A: Create as many user profiles as your family needs - there's no limit.

**Q: Can I delete a user?**
A: Yes, in Grown-up Mode, tap the user's settings and select "Delete User."

**Q: Can each child have different routines?**
A: Absolutely! Each user has their own personalized routines.

### Card Library

**Q: What is the Card Library?**
A: Pre-made activity cards for common routines. Save time by importing these instead of creating from scratch.

**Q: Can I add my own cards to the library?**
A: Currently, you can save your custom cards within each user's profile.

### Data and Sync

**Q: Where is my data stored?**
A: By default, all data is stored locally on your device. No internet connection required!

**Q: How do I backup my routines?**
A: Use the Export feature to save your routines as a file, or enable Google Drive sync for automatic backup.

**Q: Can I use StackMap on multiple devices?**
A: Yes! Export your routines from one device and import them on another, or use Google Drive sync.

### Troubleshooting

**Q: StackMap isn't loading properly**
A: Try:
1. Refreshing the page
2. Clearing your browser cache
3. Using a different browser
4. Checking your internet connection (for first load)

**Q: I lost my routines**
A: If you cleared browser data, routines may be lost unless you exported them or used Google Drive sync.

**Q: Cards won't mark as complete**
A: Make sure you're not in Grown-up Mode. Exit edit mode to use tap-to-complete.

**Q: Google Drive sync isn't working**
A: Check that:
1. You're signed into Google
2. You've granted permissions
3. You have internet connection
4. You have space in Google Drive
