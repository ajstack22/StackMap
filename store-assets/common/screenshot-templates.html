How to Create Screenshots

  1. Open StackMap in your browser at the correct viewport size
  2. Set up the app with sample data (use diverse names and activities)
  3. Navigate to the screen you want to capture
  4. Use browser DevTools to set exact dimensions:
    • Phone: 1080 x 1920
    • Tablet: 1600 x 2560
  5. Take screenshot using:
    • Chrome: DevTools > ⋮ > Capture screenshot
    • Firefox: Screenshot button in DevTools
    • Safari: Develop > Show Web Inspector > Screenshots
  6. Optional: Add device frames using tools like:
    • Rotato
    • Mockup World
    • Device Frames
