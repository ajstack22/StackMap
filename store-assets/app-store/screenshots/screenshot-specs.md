# Apple App Store Screenshot Specifications

## Requirements
- Format: PNG or JPEG (PNG preferred)
- Minimum: 3 screenshots
- Maximum: 10 screenshots per device type
- Must include screenshots for applicable device sizes

## iPhone Screenshots (Required)

### 6.7" Display (iPhone 15 Pro Max, 14 Pro Max)
- Dimensions: 1290 x 2796 pixels
- Required for App Store

### 6.5" Display (iPhone 11 Pro Max, XS Max)
- Dimensions: 1242 x 2688 pixels or 1284 x 2778 pixels
- Legacy support

### 5.5" Display (iPhone 8 Plus)
- Dimensions: 1242 x 2208 pixels
- Legacy support

### Recommended iPhone Screenshots:
1. **Welcome/Home** - Beautiful first impression with user profiles
2. **Today's Routine** - Child's daily schedule with emoji cards
3. **Interactive Completion** - Tapping cards to mark complete
4. **Create Activity** - Easy emoji-based card creation
5. **Card Library** - Pre-made routine templates

9. **Tomorrow Planning** - Future routine preparation
10. **Family Overview** - Multiple users managed easily

## App Preview Guidelines

### Design Principles:
- Show real app interface (no mockups)
- Use device frames to add context
- Maintain app's visual identity
- Include status bar for authenticity
- Show diverse, inclusive content

### Content Strategy:
- Lead with most compelling feature
- Show complete user journey
- Highlight unique benefits
- Include variety of use cases
- Demonstrate ease of use

### Text Overlays:
- Maximum 3 lines of text
- Use app's Comic Relief font
- High contrast for readability
- Action-oriented language
- Examples:
  - "Visual Routines That Click"
  - "Independence Starts Here"
  - "Every Tap Builds Confidence"
  - "Designed for Special Needs"

### Visual Elements:
- App's purple gradient backgrounds
- Colorful emoji selections
- Clean, uncluttered layouts
- Success states (green checkmarks)
- Smooth transitions between screens

## Screenshot Order Strategy:
1. **Hook** - Most visually appealing/unique feature
2. **Core Value** - Primary benefit demonstration
3. **Key Features** - 3-4 essential capabilities
4. **Differentiation** - What makes StackMap special
5. **Social Proof** - Success/completion screens
6. **Call to Action** - Invite to try

## Accessibility Considerations:
- Ensure text is readable at small sizes
- Use high contrast elements
- Show accessibility features in action
- Include diverse user representations

## Localization Requirements:
- Create unique screenshot sets per locale
- Translate all visible UI text
- Use culturally appropriate content
- Adjust for RTL languages if applicable
