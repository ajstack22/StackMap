# Apple App Store Icon and Graphics Specifications

## App Icon (Required)
- **Dimensions**: 1024 x 1024 pixels
- **Format**: PNG (no transparency)
- **Color Space**: sRGB or P3
- **No rounded corners** (iOS applies them automatically)

### Icon Design Principles:
- Simple, memorable design
- Works at all sizes (from 20pt to 1024pt)
- Consistent with app's visual identity
- No text in icon (except single letters/numbers)
- Test on various backgrounds

### Current Icon Analysis:
Based on the app's current icon:
- Three horizontal bars suggesting stacked cards
- Purple/indigo gradient background
- Clean, minimalist design
- Good scalability

## App Store Marketing Materials

### App Preview Poster Frame
- **Purpose**: Static image shown before video plays
- **Dimensions**: Same as device screenshots
- **Best Practice**: Most compelling moment from preview

### What's New Graphics
- **Purpose**: Highlight updates in new versions
- **Dimensions**: Flexible, but maintain aspect ratios
- **Usage**: Version release notes

## Brand Guidelines Summary

### Logo Variations:
1. **Full Logo**: Icon + "StackMap" text
2. **Icon Only**: For small spaces
3. **Wordmark**: Text only for certain contexts

### Safe Space:
- Minimum clear space around logo = 1/4 of icon height
- Never squeeze or stretch logo
- Maintain aspect ratio always

### Color Usage:
```
Primary Gradient:
- Start: #667eea
- End: #5a67d8
- Angle: 135°

Secondary Colors:
- Success Green: #48bb78
- Warning Yellow: #f6e05e
- Error Red: #fc8181

```

### Approved Backgrounds:
