# StackMap Mushroom Kingdom Demo

Welcome to the StackMap demo featuring beloved Mushroom Kingdom characters! This interactive demo showcases how StackMap can help kids with special needs manage their daily activities in a fun, engaging way.

## 🎮 Demo Features

### Four Unique Characters
- **Mario** (🔴): Focuses on speech therapy, occupational therapy, and social skills
- **Luigi** (🟢): Activities for anxiety management, confidence building, and sensory integration
- **Toad** (🍄): AAC communication, visual schedules, and structured routines
- **Princess Peach** (👑): Emotion regulation, art therapy, and life skills

### Special Needs Integration
Each character's activities blend fun Mushroom Kingdom themes with real therapeutic activities:
- Speech Therapy sessions
- Occupational Therapy exercises
- Sensory breaks and integration
- Social skills practice
- Communication board usage
- Life skills development
- Anxiety and emotion management

### Interactive Elements
- Switch between characters using the character buttons at the bottom
- Each character has their own theme color and personalized activities
- Try Edit Mode to see how parents/therapists can customize activities
- Explore the Library feature for quick activity templates
- Complete activities and see visual progress

## 🚀 Getting Started

1. Visit `stackmap.app/demo`
2. The demo loads automatically with Mario selected
3. Click the character buttons at the bottom to switch between users
4. Try clicking activities to mark them complete
5. Enter Edit Mode to see customization options

## 👨‍👩‍👧‍👦 For Parents & Educators

This demo demonstrates how StackMap can:
- Make daily routines visual and fun
- Integrate therapy activities seamlessly
- Provide structure while maintaining flexibility
- Support multiple users with different needs
- Celebrate achievements with visual feedback

## 🎯 Key Benefits Highlighted

- **Visual Learning**: Perfect for kids who learn better with pictures and colors
- **Routine Building**: Helps establish and maintain daily routines
- **Motivation**: Game-like elements keep kids engaged
- **Flexibility**: Easy to modify activities as needs change
- **Independence**: Kids can track their own progress

## 💡 Demo Tips

- Notice how each character's activities reflect their personality AND therapeutic needs
- The Group Library contains shared activities all characters can use
- Activities are color-coded by type (recurring, frequent, single-use)
- The interface works great on tablets - perfect for kids to use independently

## 🔄 Resetting the Demo

Click the "Reset Demo" button in the banner to restore the original configuration and start fresh.
