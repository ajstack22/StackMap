# StackMap Documentation

This directory contains all documentation for the StackMap project, organized by category.

### `/android/`
- `ANDROID_BUILD_SETUP.md` - Android build environment setup
- `ANDROID_FIXES.md` - Common Android issues and fixes
- `GOOGLE_PLAY_SETUP_GUIDE.md` - Google Play Store setup
- `GOOGLE_PLAY_TESTING.md` - Testing on Google Play

### `/ios/`

### `/deployment/`

### `/development/`
- `BUILD_TROUBLESHOOTING.md` - Build issue solutions

- `FIX_MATERIAL_ICONS.md` - Material Icons setup
- `PROJECT_STRUCTURE.md` - Project organization
- `SCRIPTS_README.md` - Script documentation
- `SCROLLING_ISSUE_RESEARCH_REQUEST.md` - Scrolling research
- `SCROLLING_ISSUE_RESEARCH_RESPONSE.md` - Scrolling solutions
